# Changelog

## 2.00 - Unreleased

- Ported UniFlash from Pascal to C for Open Watcom 2 and 16-bit DOS.
- Added a reproducible containerized 386/huge-model build environment.
- Converted the flash database to declarative manufacturer files.
- Ported flash identification and manufacturer programming algorithms.
- Ported chipset, PCI, PCI-card, CT-Flasher, CMOS, XMS, and physical-memory
  access layers.
- Added the 80×25 text-mode GUI and English language definition.
- Added non-destructive ROM, boot-block, and CMOS backup functions.
- Restored safe command-line compatibility options.
- Added host-side regression tests and Open Watcom toolchain checks.

Destructive application workflows remain disabled pending completion and
physical-hardware validation.
